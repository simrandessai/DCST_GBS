# DCST_GBS
DCST NIRF project (simple version) - plain Java, no packages.

Compile and run (from this folder):
    mkdir -p out
    javac -d out src/*.java
    java -cp out DCST

Main class: DCST. It runs the 10 features one after another, then prints the NIRF listing.
Staff/student names, placement numbers and the MSc AI / MSc DS / BSc-MSc DS subjects are sample or assumed data.
